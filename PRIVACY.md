# Privacy Policy

Last updated: 2026-11-11

Nekori Board Tool ("the App") is a private tool used by a single person, its owner. It
is not distributed to, and does not operate on behalf of, anyone else.

## Data the App accesses

The App calls the Pinterest API v5 with the owner's own OAuth token. It reads and
modifies only the owner's own boards, board sections and Pins:

- board names, descriptions and IDs
- board section names and IDs
- Pin IDs, titles, descriptions, destination links and image URLs

## Where data is stored

Everything stays on the owner's own computer. Board and Pin metadata may be cached in
local files on that machine for backup and rollback purposes. There is no server
operated by the App or its author, so no data is transmitted to one.

## Sharing

No data is sold, shared, transferred or disclosed to any third party. There is no
analytics, advertising or tracking of any kind.

## Retention and deletion

Local caches can be deleted by the owner at any time. API access can be revoked at any
time from the owner's Pinterest account settings, which immediately invalidates the
OAuth token.

## Changes

Any change to this policy is committed to this repository, and the date at the top is
updated at the same time.
